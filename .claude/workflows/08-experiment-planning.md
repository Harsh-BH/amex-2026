# Workflow 08 — Experiment Planning

**Objective:** A prioritized plan for spending the ≤10 submissions on high-information experiments.
**Prerequisites:** Workflows 03–07 (a candidate framework exists).

## Steps
1. List candidate hypotheses (term additions, transforms, weight changes), each with expected effect + business rationale.
2. Rank by information value vs submission cost; prefer those validatable internally first.
3. Define the internal-validation plan (top-20% stability) that gates a submission.
4. Reserve submissions: baseline early, keep budget for late refinement.
5. Consult **leaderboard-strategist** agent for sequencing.

## Validation
- Each planned experiment has a hypothesis + internal-validation gate.

## Deliverables
- An ordered experiment backlog (in `experiment-history.md` notes / roadmap).

## Exit criteria
- Clear order of experiments; no plan to "submit and see" blindly.
