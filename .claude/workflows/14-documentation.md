# Workflow 14 — Documentation

**Objective:** Accurate, audit-ready documentation matching the implemented solution.
**Prerequisites:** A finalized (or milestone) framework.

## Steps
1. Invoke **documentation** (`/document`) or the **doc-writer** agent.
2. Complete every `framework-doc.md` section; ensure it matches `scoring.py` exactly.
3. Refresh `memory/`: decision-log, assumptions, experiment-history, roadmap.
4. Prune stale claims; verify reproducibility statement (one command rebuilds the file).

## Validation
- Writeup ↔ code consistency confirmed; no stale memory.

## Deliverables
- Submission-ready Framework writeup; current memory.

## Exit criteria
- A judge could reproduce and understand the solution from the docs alone.
