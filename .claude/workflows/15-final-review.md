# Workflow 15 — Final Review (R1 close-out)

**Objective:** Ship the most defensible submission and hand off cleanly to R2/R3.
**Prerequisites:** Iteration done; budget mostly/fully used.

## Steps
1. Run the **`before-final-delivery` checklist**.
2. Dispatch the **framework-critic** agent for a last adversarial pass.
3. Select the final submission by **defensible logic + internal robustness**, not just top public LB (hidden 30%).
4. Confirm reproducibility end-to-end; writeup matches code; no §16 violation.
5. Capture R2/R3 handoff notes (business + feature insights reusable for the case study).

## Validation
- framework-critic verdict = ship; checklist green; reproducible.

## Deliverables
- Final R1 submission + complete writeup; R2/R3 handoff notes.

## Exit criteria
- R1 submitted with confidence; knowledge preserved for later rounds.
