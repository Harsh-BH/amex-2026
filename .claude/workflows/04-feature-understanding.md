# Workflow 04 — Feature Understanding

**Objective:** Know each `f1`–`f23` precisely: meaning, role, scale, missingness, interactions.
**Prerequisites:** Workflows 02, 03.

## Steps
1. Invoke **data-understanding**; decode via `terminology.md`.
2. For each feature, record stats + P&L role + interactions in `feature-doc.md` / `feature-notes.md`.
3. Flag anomalies (negatives, non-zero floors, scale mismatches) → `assumptions.md`.
4. Note structural missingness clusters and what each implies (segment signals).

## Validation
- No feature is "unknown"; anomalies are registered as assumptions.

## Deliverables
- Completed feature notes; resolved/queued assumptions.

## Exit criteria
- Ready to explore relationships with full feature comprehension.
